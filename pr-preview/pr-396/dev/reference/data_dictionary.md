# Data dictionary

An overview of the output data sets generated by the package, their data
types, and the definitions of the variables.

## Usage

``` r
data_dictionary
```

## Format

### `data_dictionary`

- dataset:

  Name of the dataset

- column:

  Name of the column

- typeof:

  Data type of the column

- definition:

  Description of what the column stands for

- value:

  Which values are allowed for the column
